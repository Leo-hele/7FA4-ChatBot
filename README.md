# 7FA4聊天器

## 功能

可以给其他用户发送消息。
消息格式：
```
@目标用户1、目标用户2、...：消息内容
```
（目标用户：全名、用户号或特殊名称）
## 特殊名称
所有人：所有用户 \
我：当前用户

## 安全

静态数据以一串$32$字节（$256$位，破解需要尝试$2^{128}=1.1579208923731619542357098500869\cdots\times10^{77}$种可能）的`bytes`串的密钥加密。

内置代码编译为`pyd`文件，几乎无法解密（解密了也不知道密钥是什么）。

动态数据几乎不会保存任何敏感信息，只会保存加密后的`Cookie`。
